One page, three files

You are looking at a web page built from index.html, styles.css and script.js. Each section below explains one file and lets you try it.

X-ray view draws a dashed box around each HTML element. The box is CSS. The switch is JavaScript. The elements are HTML.

1. index.html: what is on the page

HTML is a set of elements. Each element has an opening tag, content, and a closing tag. The tag tells the browser what the content is: a heading, a paragraph, a list, a button. 

<p>Hello, world</p>

2. styles.css: how it looks

CSS is a list of rules. Each rule picks elements (the selector) and sets properties to values. 

.sample-card {          ← selector: which elements?
  background: #ffe9a8;  ← property: value
  border-radius: 12px;  ← another property: value
}

Rule of thumb: if you want to change how something looks (colour, size, spacing, layout), edit styles.css.

3. script.js: what happens when you act

JavaScript runs instructions when something happens: a click, a key press, a typed word. A typical script does three things: find an element, listen for an event, and change something. 

const button = document.querySelector("#count-btn");   // 1. find
button.addEventListener("click", () => {               // 2. listen
  count = count + 1;
  output.textContent = count;                           // 3. change
});

    How the three files connect

    The browser opens index.html first. Two lines inside it pull in the other files:

    <head>
  <link rel="stylesheet" href="styles.css">   ← loads the CSS
</head>
<body>
  ...content...
  <script src="script.js"></script>         ← loads the JavaScript
</body>

    The files find each other through names the HTML gives out: id and class.

    HTML:  <button id="count-btn" class="quiet">Add one</button>
CSS:   .quiet { background: none; }          /* styles by class */
JS:    document.querySelector("#count-btn")  /* finds by id */
